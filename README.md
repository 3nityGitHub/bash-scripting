# Bash Scripting project

Progressive bash scripting covering Linux administration, process
management, and deploying/running a Node.js application on a server.

## Project
1. Linux Mint VM setup and inspection
2. Install Java with version checks
3. List the current user's processes
4. Sort processes by CPU or memory
5. Limit the number of processes shown
6. Install Node.js and run an app with environment variables
7. Check the app started and find its listening port
8. Configure a log directory for the app
9. Run the app as a dedicated service user
